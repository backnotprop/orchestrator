# @backnotprop/orchestrator-cli

The local CLI behind
[Orchestrator](https://github.com/backnotprop/orchestrator), a portable skill
that lets one agent orchestrate many models and agents across providers.

## Install

```sh
npm install -g @backnotprop/orchestrator-cli
```

## Start

```sh
orchestrator --help
orchestrator doctor --json --compact
```

Requires Node.js 24 or newer.
