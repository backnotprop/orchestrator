# @backnotprop/orchestrator-agent

Agent-facing tools, parent-agent sessions, diagnostics, and event rendering for
[Orchestrator](https://github.com/backnotprop/orchestrator).

Most users should install
[`@backnotprop/orchestrator-cli`](https://www.npmjs.com/package/@backnotprop/orchestrator-cli)
instead of using this package directly.

Requires Node.js 24 or newer.
